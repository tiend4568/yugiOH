# Yu-Gi-Oh! (v1.1)

Trò chơi đấu bài ma thuật phát triển bằng Unity (C#), hỗ trợ cả **Đấu với AI (Singleplayer)** và **Đấu Online 1v1 khác mạng (Multiplayer)**.

## 🎮 Tải game (Dành cho người chơi Windows)
👉 **[Tải bản mới nhất (YuGiOh v1.1) tại trang Releases](https://github.com/tiend4568/yugiOH/releases/latest)**

**Hướng dẫn mở game:**
1. Truy cập link trên và tải file `YuGiOh_v1.1.rar`.
2. Giải nén toàn bộ thư mục ra máy tính.
3. Mở trực tiếp file `yugiOH.exe` bên trong để chơi *(lần đầu nếu Windows Defender Firewall hiện thông báo, chọn **Allow access**)*.

## ✨ Điểm mới ở phiên bản v1.1
- **Đấu Online 1v1 xuyên mạng (Internet / khác Wi-Fi & LAN):** Tạo phòng hoặc vào phòng nhanh bằng **ID Phòng 6 số** và **Mật khẩu phòng**.
- **Cơ chế phản kích khi bị tấn công:** Tự động mở menu chọn kích hoạt các lá bài Phép/Bẫy đang úp (hoặc bỏ qua) ngay khi bị đối thủ tấn công.
- **Tối ưu luật bài & Trận đấu:** Hoàn thiện logic bài Phép , hỗ trợ **Chơi lại (Rematch)** và xử lý thắng tự động khi đối thủ thoát trận.
