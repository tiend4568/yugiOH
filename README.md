# Yu-Gi-Oh!

Trò chơi đấu bài ma thuật phát triển bằng Unity (C#).

## 🎮 Tải game (Dành cho người chơi Windows)
👉 **[Tải bản cài đặt mới nhất tại trang Releases](https://github.com/tiend4568/yugiOH/releases)**

**Hướng dẫn mở game:**
1. Truy cập link trên và tải file `YuGiOh-v1-Win64.rar`.
2. Giải nén toàn bộ thư mục ra máy tính.
3. Mở trực tiếp file `.exe` bên trong để chơi.
